# API Security Risk Analysis

Cyber Security Task 3

### Objective

The objective of this task was to perform a read-only API Security Risk Analysis on a public test API, identify common API security risks, assess their potential business impact, and provide remediation recommendations.

---

## Target API

**JSONPlaceholder Test API**

https://jsonplaceholder.typicode.com

## Scope

### In Scope

* Public API endpoint review
* Response data inspection
* Authentication analysis
* Authorization observations
* HTTP header inspection
* Security risk identification

### Out of Scope

* Vulnerability exploitation
* Denial-of-Service testing
* Brute-force attacks
* Authentication bypass attempts
* Testing private or production systems

---

## Methodology

The following methodology was used during the assessment:

1. Reviewed publicly available API documentation.
2. Selected test endpoints for analysis.
3. Sent requests using Postman.
4. Examined API responses and exposed data.
5. Reviewed HTTP response headers.
6. Evaluated authentication and authorization controls.
7. Identified potential security risks.
8. Assigned risk severity levels.
9. Proposed remediation recommendations.
10. Documented findings in a professional security report.
